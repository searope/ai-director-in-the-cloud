Put your keyframe images here as `01.png`, `02.png`, `03.png`, ... (any of png/jpg/webp).

- Use the same aspect ratio for every keyframe; they are center-cropped to the render size.
- Consecutive keyframes should be reachable in ~5 seconds of motion. Big jumps (new scene,
  totally different pose) work better with an extra in-between keyframe.
